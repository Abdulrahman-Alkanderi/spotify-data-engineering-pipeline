# spotify-api-btach-pipeline

Btach ETL pipeline with python to ingest and process datasets from spotify api


# overview :

this project showcases how to implent a batch pipeline using spotify web api to ingest new released
album data, transforms semi structured json responses, and proudces datasets that can be used for 
analytical use
